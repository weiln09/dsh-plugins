# dsh-plugins

A collection of plugins for [DSH](https://github.com/deepseek-ai).

## Plugins

| Plugin | Description |
|---|---|
| [`dsh-skill-manager`](plugins/dsh-skill-manager) | Browse, import (zip/GitHub), edit, delete and update DSH skills, and scope each skill to global or specific workspaces. |
